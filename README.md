# OkiDock

Tes serveurs Docker, dans la barre de menus du Mac.

Ce dépôt ne contient que les versions publiées d'OkiDock : l'app (DMG) et le flux de mises à jour
(`appcast.xml`) lu automatiquement par l'application.

## Télécharger

Dernière version : [Releases](https://github.com/mael50/okidock-releases/releases/latest).

Configuration requise : macOS 14 Sonoma ou plus récent, Mac Apple Silicon.

Au premier lancement, macOS peut refuser d'ouvrir l'app (elle n'est pas encore signée par un compte
développeur Apple) : Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ».
